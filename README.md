# project-2025

Código fuente recuperado de Google Drive y clasificado por evidencia temporal de 2025.

## Proyectos

- `colab_whisper/` — código fuente extraído de dos notebooks de Google Colab creados y modificados el 12 de diciembre de 2025. Incluye instalación/uso de OpenAI Whisper para transcripción en español, combinación de archivos SRT y una clasificación heurística de intervenciones en roles E1, E2 e I1.

## Conservación del origen

Los archivos originales `Untitled0.ipynb` y `Untitled1.ipynb` permanecen en Google Drive porque GitHub contiene por ahora el código fuente extraído de sus celdas, no una copia completa y verificada de los notebooks con todos sus metadatos/salidas. Por la regla de protección contra pérdida de datos, no deben eliminarse del Drive.

Se excluyen dependencias descargadas, cachés, artefactos generados, credenciales y secretos.

## P13_sistematizador_selenium_v14

- Origen: Google Drive, `Nueva carpeta/Proyectos_Exportados/P13_sistematizador_selenium_v14`.
- Periodo: 2025; el README original conserva modificación del 30 de diciembre de 2025.
- Propósito documentado: generar un prompt de sistematización, ejecutar mediante Selenium y Edge, y cargar el resultado en SQL Server.
- Tecnologías: Python, Selenium, SQL Server, ODBC y scripts PowerShell.
- Estructura: `main.py`, `config.py`, `src/`, `scripts/`, `requirements.txt`, `db_config.example.json` y README original.
- Módulos: construcción de prompts, lectura de insumos, consultas y carga SQL, captura mediante Selenium y utilidades de salida.
- Copia: 16 archivos originales; se conserva su estructura. La configuración de ejemplo contiene un marcador de contraseña, no una contraseña real.
- Observación: las rutas Windows del original requieren adaptación al equipo de ejecución. Las credenciales reales no están incluidas en esta carpeta.
